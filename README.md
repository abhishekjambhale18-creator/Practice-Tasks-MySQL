### 📌 Project Overview
This repository contains multiple standalone SQL practice tasks designed to strengthen core database skills.  
Each task includes table creation, sample data, and practice queries on different business scenarios.

### ✨ Topics Covered

**Basics**
- `CREATE DATABASE`, `CREATE TABLE`
- `INSERT`, `UPDATE`, `DELETE`, `TRUNCATE`, `DROP`
- `ALTER TABLE` (ADD, DROP, MODIFY, RENAME)

**Constraints**
- Primary Key, Foreign Key
- NOT NULL, UNIQUE, CHECK, DEFAULT

**Querying**
- `WHERE`, `BETWEEN`, `IN`, `LIKE`
- `ORDER BY`, `LIMIT`, `OFFSET`
- `GROUP BY`, `HAVING`
- Aggregate functions (`COUNT`, `SUM`, `AVG`, `MAX`, `MIN`)

**Advanced**
- Window functions (`ROW_NUMBER`, `RANK`, `DENSE_RANK`, `LAG`, `LEAD`, running totals)
- JOINs (`INNER`, `LEFT`, `RIGHT`, self-join)
- Subqueries (`IN`, `NOT IN`, `ANY`, `ALL`, correlated)

2. Run each task file separately
